
# HR-Analytics-PowerBI

**HR Analytics Dashboard using Power BI and MySQL**

## 📌 Project Overview

The HR Analytics project focuses on analyzing employee data, salary distribution, workforce information, performance, and HR trends using MySQL and Microsoft Power BI.

The goal is to transform raw HR data into meaningful insights through SQL queries, interactive visualizations, KPI cards, and a multi-page dashboard to support data-driven HR decision-making.

## 🎯 Project Objectives

* Analyze employee and workforce distribution.
* Understand salary and compensation patterns.
* Explore employee performance and HR trends.
* Identify meaningful patterns in the available HR data.
* Present key findings through interactive Power BI dashboards.

## 🛠️ Tools & Technologies

* **MySQL** — Database creation, data management, and SQL analysis.
* **Microsoft Power BI** — Interactive dashboard development and visualization.
* **DAX** — Measures and calculated metrics.
* **SQL** — Data retrieval, aggregation, joins, and analysis.

## 📊 Dashboard Pages

### 1. Home Dashboard

Provides an overview of important HR metrics using KPI cards and visualizations.

### 2. Workforce Analysis

Explores employee distribution and workforce-related patterns.

### 3. Salary Analysis

Analyzes salary distribution and compensation-related metrics.

### 4. Insights & Conclusion

Summarizes the key findings and potential recommendations based on the analysis.

## 📂 Project Files

* `hr_analysis05_.pbix` — Power BI dashboard file.
* `Enterprise HR project database.sql` — MySQL database script.
* `Screenshot files` — Visual previews of the dashboard pages.

## 💡 Key Learning Outcomes

* Designing and managing a relational database using MySQL.
* Writing SQL queries to analyze HR data.
* Building multi-page interactive reports in Power BI.
* Creating KPIs, visualizations, and DAX calculations.
* Communicating analytical findings through dashboards.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Open the SQL file in MySQL Workbench and execute the script as appropriate for your database setup.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. If prompted, configure the data source and update the connection settings.
5. Explore the dashboard pages and interactive visualizations.
